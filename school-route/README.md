# 미미 프레쉬 — 거래처·영업 동선 모바일 웹앱

서버 없이 휴대폰 브라우저에서 바로 쓰는 앱입니다. 메뉴는 4개입니다.

| 메뉴 | 하는 일 |
|---|---|
| **거래처** | 학교·기관을 등록해 목록으로 관리. 담당자에게 바로 전화·문자, 주소 복사, 방문 기록 |
| **영업** | 오늘 갈 곳을 검색해 하나씩 추가 → **동선 짜기** → 순서·거리·지도 |
| **서류** | 견적서 작성 → 원본 양식 그대로 엑셀 파일로 받기 |
| **설정** | 사무실 위치, 카카오 키, 계정(로그인), 파일 백업 |

> 아래 카카오·Supabase·GitHub 메뉴 이름은 **2026-11-13에 공식 문서로 확인한 것**입니다.
> 화면이 자주 바뀌므로 이름이 조금 다르면 비슷한 메뉴를 찾으세요.

## 1. 쓰는 방법

### 거래처
- 오른쪽 위 **＋** → 이름을 일부만 써도 추천 목록이 뜹니다. 고르면 주소와 위치가 자동으로 들어갑니다.
  추천에 없으면 주소를 직접 쓰고 **주소로 위치 찾기**를 누릅니다.
- 구분은 **초 / 중 / 고 / 기관 / 기타** 5가지입니다.
- 보는 순서: **최신순**(방금 추가한 것이 위) / **구분별**(초·중·고… 묶음) / **가까운순**(사무실 기준).
- 검색칸은 이름·담당자·주소·메모를 모두 찾습니다. 초성(`ㄱㄴㅊ`)이나 띄엄 글자(`가초`)도 됩니다.
- 목록의 전화기 단추를 누르면 담당자에게 바로 전화가 걸립니다.
- 거래처를 누르면 전화 · 문자 · 길안내 · 영업에 추가 · 주소 복사 · 영업 상태 · 방문 기록이 한 화면에 나옵니다.

### 영업
1. 검색칸에 갈 곳 이름을 씁니다. 내 거래처가 먼저, 그 아래에 카카오 검색 결과가 추천으로 뜹니다.
2. 추천을 누르면 목록에 추가되고, 검색칸에 바로 다음 곳을 쓸 수 있습니다.
3. 목록 오른쪽 단추: **주소 복사**, **빼기**.
4. 다 넣었으면 **동선 짜기**. 사무실 출발 → 모든 곳 방문 → 사무실 도착의 가장 짧은 순서를 계산하고 지도에 번호와 선으로 보여 줍니다.
5. 순서 바꾸기: 왼쪽 손잡이를 누른 채 끌거나 화살표. 거리가 바로 다시 계산됩니다.
6. **카카오내비**를 누르면 카카오내비 앱이 그 방문지로 바로 안내를 시작합니다. **카카오맵**은 카카오맵 앱의 자동차 길찾기로 넘어갑니다.
   **방문 완료**를 누르면 오늘 날짜로 방문 기록이 남습니다.
   (카카오내비는 설정에 카카오 JavaScript 키가 있어야 하고, 휴대폰에 카카오내비 앱이 없으면 설치 화면으로 갑니다)
7. 거래처에 없는 곳도 추가할 수 있고, **거래처로 등록**을 누르면 거래처 목록에 들어갑니다.

### 서류 (견적서)
1. 처음 한 번: 서류 화면 맨 위 **양식 파일 올리기**로 내용이 비어 있는 견적서 양식 엑셀(.xlsx)을 올립니다.
   양식에는 사업자번호·계좌·도장이 있어 **공개 저장소(GitHub)에는 올리지 않습니다.** 이 기기와, 로그인했다면 내 Supabase 프로젝트(본인만 볼 수 있음)에만 저장됩니다.
2. **새 견적서** → 받는 곳(거래처 검색), 견적일, 제목, 품목(최대 6줄: 품목·규격·수량·단가), 작업 내용, 기타사항을 넣습니다.
   금액 없이 해 주는 항목은 **서비스로 진행**을 켜면 합계 칸에 "서비스로 진행"이라고 들어갑니다.
3. **엑셀 파일로 받기**를 누르면 양식에 값만 채운 엑셀이 만들어집니다. 로고·도장·테두리·수식은 원본 그대로입니다.
   휴대폰이 지원하면 **엑셀 파일 공유** 단추도 나와 카카오톡·메일로 바로 보낼 수 있습니다.
4. 거래처 정보 화면의 **이 거래처로 견적서 작성**으로도 시작할 수 있고, **복사해서 새 견적**으로 지난 견적을 고쳐 쓸 수 있습니다.
5. **발송 완료로 표시**를 누르면 거래처 상태가 "견적 발송"으로 바뀝니다.

견적 내용과 양식 파일 모두 로그인하면 서버에 올라가 다른 기기에서도 쓸 수 있습니다.

## 2. 계산 방식과 한계 (정직하게)

- **방문 순서는 직선거리(하버사인)로 계산**합니다. 강·산·일방통행은 순서 계산에 반영되지 않습니다.
- **12곳 이하**: 가능한 모든 순서를 빠짐없이 따지는 방식(Held-Karp)으로 직선거리 기준 가장 짧은 순서를 구합니다.
- **13곳 이상**: 최근접 이웃 + 2-opt 근사 계산입니다. (13~15곳 200문제 시험: 정답보다 평균 1.6%, 최악 16% 길었음)
- **카카오 REST API 키를 넣으면** 정해진 순서대로 실제 자동차 경로를 받아 **도로 거리·예상 시간·도로를 따라가는 선**을 보여 줍니다.
  순서 자체를 도로 거리로 다시 계산하지는 않습니다. (카카오의 공개 길찾기에는 여러 지점 사이 거리를 한 번에 주는 기능이 없습니다)
- 계산 검증: `node test/verify.js` — 샘플 5곳의 순서 120가지를 전부 나열해 앱의 답과 비교하고, 무작위 2,000문제도 같은 식으로 비교합니다.

## 3. 카카오 키

1. <https://developers.kakao.com> 로그인 → **앱** → 앱 추가.
2. **[앱 설정] → [플랫폼 키] → JavaScript 키** 를 누릅니다.
3. 그 화면의 **JavaScript SDK 도메인**에 사이트 주소를 넣습니다. (앱의 설정 화면에 "등록할 주소"가 표시됩니다. 경로는 빼고 `https://아이디.github.io` 까지만)
4. 왼쪽 **[카카오맵] → [사용 설정] → 상태 ON**. 안 켜면 지도와 검색이 안 됩니다.
5. JavaScript 키를 복사해 앱 **설정 → 카카오 연결**에 넣고 **키 저장**.

### 자동차 경로까지 보려면 (선택)
- 같은 **[플랫폼 키]** 화면의 **REST API 키**를 복사해 앱 설정의 REST API 키 칸에 넣습니다.
- REST API 키의 **"호출 허용 IP 주소"는 비워 둬야** 합니다. (휴대폰 IP는 계속 바뀝니다)
- 무료 한도: 다중 경유지 길찾기 하루 5,000건, 자동차 길찾기 하루 10,000건. 같은 경로는 다시 조회하지 않게 만들어 두었습니다.
- **확인이 필요한 점**: 카카오모빌리티 직원 답변이 "무료 한도 안이면 제휴 없이 사용 가능"(2026-11)과 "상업적 목적이면 한도 안이라도 사전 제휴 필요"(2026-09)로 엇갈립니다.
  영업에 쓰는 것이 여기에 해당하는지는 카카오모빌리티에 직접 문의해 확인하는 것이 안전합니다.
- REST API 키는 이 기기와 내 Supabase 프로젝트에만 들어가고, GitHub 저장소에는 올라가지 않습니다.

### 요금
- 카카오맵 무료 한도(하루): 지도 30만 건, 장소 검색 10만 건, 주소→좌표 10만 건.
- 추천 검색은 글자를 칠 때마다(0.35초 쉬면) 장소 검색 1건을 씁니다. 한 곳 찾는 데 보통 3~6건입니다.
- 2026-07-21부터 카카오맵 무료 한도는 **그 계정에서 카카오맵을 처음 켠 앱 1개**에만 적용됩니다.

### 안 될 때
| 증상 | 확인할 것 |
|---|---|
| "카카오맵을 불러오지 못했습니다" | JavaScript SDK 도메인 등록, 카카오맵 사용 설정 ON, JavaScript 키가 맞는지 |
| 지도는 나오는데 검색이 안 됨 | 카카오맵 사용 설정 ON |
| 자동차 경로가 안 나오고 직선거리만 | 요약 칸에 이유가 표시됩니다. REST API 키, 호출 허용 IP(비워야 함) 확인 |

## 4. 한 번 로그인하면 계속 유지 · 모든 기기에서 같은 내용 (Supabase)

이메일과 비밀번호로 **한 번만 로그인하면 계속 로그인된 상태**로 유지됩니다. 어느 기기에서든 로그인하면 아래가 전부 따라옵니다.

- 거래처, 방문 기록, 오늘 영업 목록, 견적서
- 카카오 키 2개, 사무실 위치
- 견적서 양식 파일

**맞춰지는 방식**
- 고친 내용은 2초쯤 뒤 자동으로 서버에 올라갑니다. 위쪽 구름 단추가 초록이면 저장된 것, 주황이면 아직입니다.
- 앱을 열거나 다른 앱에 갔다가 돌아올 때마다 서버를 확인해, 다른 기기에서 바뀐 내용을 묻지 않고 가져옵니다.
- 두 기기에서 **같은 시간대에 따로 고쳤을 때만** 어느 쪽을 쓸지 묻습니다. (자동으로 덮어쓰지 않습니다)
- 인터넷이 끊겨도 이 기기에는 저장되고, 다시 연결되면 올라갑니다.
- 로그인이 풀리는 경우: 직접 로그아웃했을 때, 브라우저 데이터를 지웠을 때.

### 처음 한 번 설정 (무료, 10분쯤. 컴퓨터에서 하는 것이 편합니다)
메뉴 이름은 2026-11-13 공식 문서 기준입니다. 화면은 직접 열어 보지 못했으므로 이름이 조금 다를 수 있습니다.

1. <https://supabase.com> 가입 → **New project** → 이름과 데이터베이스 비밀번호를 정하고 만들기. (지역은 Seoul 권장)
2. 왼쪽 **SQL Editor** → 이 폴더의 `supabase-setup.sql` 내용을 통째로 붙여넣고 **Run**.
3. **Authentication** 설정의 Email 로그인 항목에서 **Confirm email 을 끕니다.**
   켜 두면 가입 확인 메일이 와야 하는데, Supabase 기본 메일은 시간당 2통·프로젝트 팀원 주소로만 보내져서 막히기 쉽습니다.
4. **Settings → API Keys**(또는 화면 위 **Connect**)에서 두 가지를 복사합니다.
   - **Project URL** (`https://○○○.supabase.co`)
   - **Publishable key** (`sb_publishable_…`). **Secret key 는 절대 쓰지 않습니다.**
5. 이 두 값을 앱에 넣습니다. 방법은 둘 중 하나.
   - **가장 편한 방법**: `js/config.js` 의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 따옴표 안에 넣어 저장소에 올립니다. 그러면 어느 기기든 사이트만 열면 로그인 화면이 나옵니다. (Publishable key 는 공개돼도 되는 키입니다)
   - 코드를 고치지 않는 방법: 첫 기기의 **설정 → 계정 · 기기 간 저장**에 넣고 저장 → 다른 기기는 **다른 기기용 링크 복사**로 만든 링크를 열면 됩니다.
6. 로그인 화면에서 이메일·비밀번호(8자 이상)를 넣고 **처음이면 계정 만들기**. 다른 기기에서는 같은 이메일·비밀번호로 **로그인**.
7. 계정을 만든 뒤 Authentication 설정에서 **Allow new users to sign up 을 끄기**를 권합니다. 다른 사람이 내 프로젝트에 가입하는 것을 막습니다. (가입해도 남의 데이터는 볼 수 없게 되어 있습니다)

### 알아둘 점
- **무료 프로젝트는 1주일 동안 사용이 없으면 일시정지됩니다.** 매일 쓰면 해당 없습니다. 정지되면 Supabase 대시보드에서 **Resume project** 를 누르면 데이터 그대로 돌아옵니다. 정지 중에도 이 기기에 저장된 내용으로 앱은 계속 쓸 수 있습니다.
- **비밀번호를 잊었을 때**: 앱에는 재설정 기능이 없습니다. Supabase 대시보드의 Authentication → Users 에서 해당 사용자의 비밀번호를 다시 정하면 됩니다.
- 무료 한도는 데이터베이스 500MB, 프로젝트 2개입니다. 이 앱의 데이터는 수 MB 이하입니다.

### 서버 없이 쓸 때
로그인 화면에서 **로그인 없이 시작**을 누르면 이 기기에만 저장합니다. 설정 → **파일 백업 → 내보내기**로 파일을 받아 보관할 수 있습니다.

## 5. 휴대폰에서 쓰도록 인터넷에 올리기 (GitHub Pages)

1. GitHub 저장소의 **Settings → Pages**.
2. **Source: Deploy from a branch** → 브랜치와 **/(root)** 선택 → **Save**.
3. 1~2분 뒤 나오는 주소 끝에 `/school-route/` 를 붙여 휴대폰에서 엽니다.
4. 브라우저 메뉴의 **홈 화면에 추가**를 꼭 하세요.
   아이폰 사파리는 7일 동안 쓰지 않은 사이트의 저장 데이터를 지우는데, **홈 화면에 추가한 앱은 예외**입니다.
   단, 홈 화면 앱과 사파리는 저장 공간이 따로라서 **홈 화면 앱에서 처음부터 입력**해야 합니다.

무료 계정은 **공개 저장소**에서만 GitHub Pages를 쓸 수 있습니다. 저장소에는 프로그램만 있고, 거래처 데이터와 키는 올라가지 않습니다.

### 컴퓨터에서 먼저 해 보기
`index.html`을 더블클릭하면 지도·검색 없이 계산까지 됩니다(설정 → 연습용 샘플 5곳 넣기).
지도까지 보려면 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`.

## 6. 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 틀과 모양 |
| `logo.png` | 회사 마크 (머리글, 빈 화면, 배경, 앱 아이콘에 사용) |
| `js/config.js` | 모든 기기 공통 값 (Supabase 주소·공개 키) |
| `supabase-setup.sql` | 서버에 저장용 표를 만드는 SQL (한 번 실행) |
| `js/route.js` | 거리·동선 계산 (AI 없음). `setDistanceProvider()`로 거리표 함수 교체 가능 |
| `js/store.js` | 저장(localStorage)·데이터 형식. 이전 버전 데이터 자동 이어받기 |
| `js/kakao.js` | 카카오맵 연결, 장소 검색, 주소→좌표, 자동차 경로 |
