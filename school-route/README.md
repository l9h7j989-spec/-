# 영업 동선 — 학교 청소·영업용 모바일 웹앱

서버 없이 휴대폰 브라우저에서 바로 쓰는 앱입니다.
거래처(학교·기관)를 등록하고, 사무실에서 가까운 순서로 보고, 오늘 방문할 곳의 가장 짧은 순서를 계산합니다.

- 화면은 3개: **거래처** / **오늘 동선** / **설정**
- 데이터는 그 휴대폰의 그 브라우저 안에만 저장됩니다. (설정 → 백업 파일 내보내기로 보관)
- 동선 계산에 AI는 쓰지 않습니다. `js/route.js` 안의 계산식만 사용합니다.

> 아래 카카오·GitHub 메뉴 이름은 **2026-11-13에 공식 문서로 확인한 것**입니다.
> 두 사이트 모두 화면이 자주 바뀌므로, 이름이 조금 다르면 비슷한 메뉴를 찾으세요.

## 1. 내 컴퓨터에서 실행해 보기

### 가장 쉬운 방법 (지도·검색 없이 맛보기)
1. 이 폴더(`school-route`)를 컴퓨터에 내려받습니다.
2. `index.html`을 더블클릭해 크롬으로 엽니다.
3. **설정 → 샘플 넣기** → **거래처** 탭에서 ✓ 체크 → **오늘 동선 → 동선 추천**.

이 방법은 카카오 키 없이 계산까지 됩니다. 다만 **지도와 장소 검색은 안 됩니다.**
(카카오맵은 등록된 사이트 주소에서만 켜지기 때문입니다.)

### 지도까지 보려면 (컴퓨터에 작은 서버 켜기)
1. 파이썬이 없으면 설치합니다. (윈도우: Microsoft Store에서 "Python" 검색 → 설치)
2. `school-route` 폴더에서 터미널(윈도우는 폴더 주소창에 `cmd` 입력 후 엔터)을 열고 아래를 입력합니다.

```bash
python -m http.server 8000
```

   (맥은 `python3 -m http.server 8000`)

3. 크롬 주소창에 `http://localhost:8000` 을 입력합니다.
4. 카카오 개발자 사이트에 `http://localhost:8000` 을 등록해야 지도가 나옵니다. (아래 3번 참고)

## 2. 휴대폰에서 쓰도록 무료로 인터넷에 올리기 (GitHub Pages)

**알아둘 점:** 무료 계정은 **공개 저장소**에서만 GitHub Pages를 쓸 수 있습니다.
공개돼도 괜찮은 이유 — 이 폴더에는 프로그램만 있고, 거래처 데이터와 카카오 키는 내 휴대폰 안에만 저장됩니다.

1. <https://github.com> 에 가입하고 로그인합니다.
2. 오른쪽 위 **＋ → New repository** → 이름 입력(예: `sales`) → **Public** 선택 → **Create repository**.
3. **uploading an existing file** 링크를 누르고, `school-route` 폴더 **안의 파일과 폴더 전부**(`index.html`, `style.css`, `js` 폴더 등)를 끌어다 놓은 뒤 **Commit changes**.
4. 저장소의 **Settings → (왼쪽 메뉴) Pages** 로 갑니다.
5. **Build and deployment → Source** 를 **Deploy from a branch** 로, Branch 를 **main** / **/(root)** 로 고르고 **Save**.
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. 보통 `https://아이디.github.io/sales/` 형태입니다.
7. 휴대폰 크롬(또는 사파리)에서 그 주소를 엽니다.
8. 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생깁니다.

이미 이 저장소 전체를 GitHub에 올려 둔 경우에는 3번을 건너뛰고 4~5번만 하면 되며,
주소 끝에 `/school-route/` 를 붙여서 엽니다.

**주의:** 컴퓨터와 휴대폰, 크롬과 사파리는 데이터가 서로 따로입니다. 옮기려면 백업 파일 내보내기 → 불러오기를 쓰세요.

## 3. 카카오 키 발급과 사이트 주소 등록

1. <https://developers.kakao.com> 에 카카오 계정으로 로그인합니다. (처음이면 개발자 등록 동의)
2. 위쪽 **앱** → **앱 추가(앱 만들기)** → 앱 이름·회사명(개인이면 본인 이름이나 상호)·카테고리를 넣고 저장.
3. 만든 앱을 누르고 **[앱 설정] → [플랫폼 키]** 로 갑니다.
4. **JavaScript 키**를 누릅니다. (REST API 키가 아닙니다. 지도에는 JavaScript 키만 됩니다)
5. 그 화면의 **JavaScript SDK 도메인**에 내 사이트 주소를 넣고 저장합니다.
   - 휴대폰용: `https://아이디.github.io` (뒤의 `/sales/` 같은 경로는 빼고 넣습니다)
   - 컴퓨터 연습용: `http://localhost:8000`
   - 앱의 **설정** 화면에 "등록할 이 사이트 주소"가 그대로 표시되니 그것을 복사해도 됩니다.
6. 왼쪽 메뉴 **[카카오맵] → [사용 설정]** 에서 **상태를 ON** 으로 바꿉니다. **이걸 안 켜면 지도가 안 나옵니다.**
7. 다시 **[플랫폼 키]** 화면에서 JavaScript 키 값을 복사합니다.
8. 우리 앱의 **설정 → ① 카카오 JavaScript 키** 칸에 붙여넣고 **키 저장**.
   "✅ 카카오맵 연결됨"이 보이면 성공입니다.

### 요금
- 카카오맵 무료 한도(하루): 지도 30만 건, 주소→좌표 변환 10만 건, 장소 검색 10만 건. 혼자 쓰는 용도로는 넘기 어렵습니다.
- **2026-07-21부터** 무료 한도는 **그 카카오 계정에서 카카오맵을 처음 켠 앱 1개**에만 적용됩니다.
  예전에 다른 앱에서 카카오맵을 켠 적이 있다면, 앱 정보에 **[카카오맵 무료 쿼터]** 표시가 있는지 확인하세요.

### 안 될 때
| 증상 | 확인할 것 |
|---|---|
| "카카오맵을 불러오지 못했습니다" | 도메인 등록(5번), 카카오맵 사용 설정 ON(6번), JavaScript 키가 맞는지(4번) |
| 지도는 나오는데 검색이 안 됨 | 카카오맵 사용 설정 ON(6번) |
| 주소를 바꿨더니 안 됨 | 새 주소를 5번에 추가 등록 |

## 4. 사용 순서

1. **설정**: 카카오 키 저장 → 사무실 이름이나 주소로 검색해 고르기.
2. **거래처 → ＋ 거래처 추가**: 이름 입력 → **검색** → 목록에서 고르면 주소·위치 자동 입력.
   검색이 안 되면 주소를 직접 쓰고 **주소로 위치 찾기**.
3. **거래처** 목록: 사무실에서 가까운 순. 왼쪽 **✓ 칸**을 누르면 오늘 방문에 들어갑니다. 전화기 그림을 누르면 전화.
4. **오늘 동선 → 동선 추천**: 순서·구간 거리·총 거리와 지도가 나옵니다.
   - 순서 바꾸기: 왼쪽 **≡** 를 누른 채 끌거나 ▲▼.
   - **카카오맵 길안내**: 카카오맵으로 넘어가 그 방문지까지 길을 찾습니다.
   - **방문 완료**: 오늘 날짜로 방문 기록이 남고, 상태가 "미방문"이면 "방문 완료"로 바뀝니다.
5. 다음 날: **오늘 목록 초기화** 후 다시 체크.

## 5. 계산 방식과 한계 (정직하게)

- **거리는 직선거리(하버사인)** 입니다. 실제 도로 거리는 이보다 깁니다. 강·산·일방통행은 반영되지 않습니다.
- **12곳 이하**: 가능한 모든 순서를 빠짐없이 따지는 방식(Held-Karp)으로 **직선거리 기준 가장 짧은 순서**를 구합니다.
  순서를 하나씩 나열하면 12곳은 약 4억 8천만 가지라 휴대폰이 멈추므로, 결과가 똑같으면서 즉시 끝나는 방식을 썼습니다.
- **13곳 이상**: 최근접 이웃 + 2-opt 근사 계산입니다. 가장 짧은 순서와 다를 수 있습니다.
  (13~15곳 200문제 시험: 정답보다 평균 1.6%, 최악 16% 길었습니다)
- 나중에 실제 도로거리로 바꾸려면 `js/route.js`의 `setDistanceProvider(함수)`에 거리표를 만드는 함수만 넣으면 됩니다.
  나머지 계산 코드는 그대로 씁니다.

### 검증 방법
```bash
node test/verify.js
```
샘플 5곳의 순서 120가지를 전부 나열해 앱의 답과 비교하고, 무작위 2,000문제도 같은 식으로 비교합니다.

## 6. 파일 구성과 데이터 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 틀과 모양 |
| `js/route.js` | 거리·동선 계산 (AI 없음) |
| `js/store.js` | 저장(localStorage)·백업 형식 |
| `js/kakao.js` | 카카오맵 연결, 장소 검색, 주소→좌표 |
| `js/app.js` | 화면 동작 |
| `test/verify.js` | 계산 검증 |

**견적서 대비:** 백업 파일에 `quotes: []` 자리를 미리 만들어 두었습니다.
견적 1건을 `{ id, clientId, date, items:[{name, qty, unitPrice}], total, status, sentAt, memo }` 로 저장하면
`clientId`로 거래처의 이름·주소·담당자·연락처를 그대로 끌어다 쓸 수 있습니다. 양식을 주시면 여기에 붙입니다.
