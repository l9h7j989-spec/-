# 개발 인수인계 (새 대화에서 이어서 작업할 때 먼저 읽기)

배관·누수 업체용 모바일 웹앱(PWA) "업무수첩". 코딩 모르는 사용자와 그 친구(사장님)가 씀. 설명은 쉬운 한국어로.

## 주소·배포
- 앱: https://l9h7j989-spec.github.io/-/plumbing/
- GitHub Pages 소스 브랜치: `claude/happy-brahmagupta-1560fj` (저장소 l9h7j989-spec/-, 공개)
- 작업 후 배포 = 작업 브랜치를 `claude/happy-brahmagupta-1560fj` 와 `claude/keen-ride-ggdqr4` 에 병합 후 push
- 고칠 때마다 `sw.js` 의 CACHE 이름 숫자 올리기 (현재 plumbing-v18) → 폰에서 앱 껐다 켜면 새 버전

## 구조 (빌드 없음, 순수 JS)
- `index.html`, `app.css`(아이폰 스타일, 다크모드), `js/app.js`(화면 전부)
- `js/db.js` IndexedDB 저장 / `js/sync.js` Supabase 동기화(나중에 고친 것이 이김, 3초 뒤 자동)
- `js/estimate-core.js` 견적 계산 / `js/xls-fill.js` 사장님 .xls 양식 칸 채우기(BIFF8 직접 수정)
- `js/hwp5.js` 누수소견서 .hwp 수정(도장 2쪽 넘어감 방지 keepPageHeight) / `js/hwpx.js` 한글 견적
- `js/memo-import.js` 지난 작업 메모(html/txt) → 날짜별 기록. 날짜 줄: `3/24`, `2023년 12월 18일`, `2025 11월 17일`, `2025 12월 30`. `12/20일로…`, `1/1-6 87`, 합계줄은 날짜 아님/제외
- 설정 화면: 메모 가져오기(전에 메모로 넣은 날은 교체), 메모로 넣은 기록만 연도별 지우기(src:'memo')

## 데이터·보안 (꼭 지킬 것)
- 데이터·양식은 사장님 Supabase(프로젝트 plumbing)에만. 표 `records`(kind/id/data/deleted), 버킷 `photos/<uid>/` (template.xlsx=.xls 내용, template.hwp)
- **사장님 상호·주소·전화·사업자번호·도장/명판 이미지·양식 파일을 GitHub(공개)에 절대 올리지 않기**
- 비밀키(service_role, 토큰)를 채팅으로 받지 않기. 사용자는 Supabase 토큰 제공을 거절함 → 대시보드 수동 안내로 진행
- 빠진 기능(요청으로 제거): AI, 밴드 업로드, 카톡 보내기/미수금 알림, .xlsx 양식, 고객명/연락처/특기사항

## 최근 상태
- 아이폰 스타일 UI 적용 완료, 2023~2025 메모 3개 파일 날짜 인식 검증(200/292/282일, 하루 최대 18줄)
- 미정 질문: 메모의 하루 끝 숫자(예: `15`, `일당 10`)를 "일당"으로 표시할지 → 사용자 답 대기
- 제안했던 것: 달력의 기록 수 숫자 배지를 작은 점으로 바꿀지 (답 대기)
