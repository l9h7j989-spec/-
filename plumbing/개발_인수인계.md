## 구조 (빌드 없음, 순수 JS)
- `index.html`, `app.css`(아이폰 스타일, 다크모드), `js/app.js`(화면 전부)
- `js/db.js` IndexedDB 저장 / `js/sync.js` Supabase 동기화(나중에 고친 것이 이김, 3초 뒤 자동)
- `js/estimate-core.js` 견적 계산 / `js/xls-fill.js` 사장님 .xls 양식 칸 채우기(BIFF8 직접 수정)
- `js/hwp5.js` 누수소견서 .hwp 수정(도장 2쪽 넘어감 방지 keepPageHeight) / `js/hwpx.js` 한글 견적
- `js/memo-import.js` 지난 작업 메모(html/txt) → 날짜별 기록. 날짜 줄: `3/24`, `2023년 12월 18일`, `2025 11월 17일`, `2025 12월 30`. `12/20일로…`, `1/1-6 87`, 합계줄은 날짜 아님/제외
- 설정 화면: 메모 가져오기(전에 메모로 넣은 날은 교체), 메모로 넣은 기록만 연도별 지우기(src:'memo')

## 데이터·보안 (꼭 지킬 것)
- 데이터·양식은 사장님 Supabase(프로젝트 plumbing)에만. 표 `records`(kind/id/data/deleted), 버킷 `photos/<uid>/` (template.xlsx=.xls 내용, template.hwp)
- **사장님 상호·주소·전화·사업자번호·도장/명판 이미지·양식 파일을 GitHub(공개)에 절대 올리지 않기**
- 비밀키(service_role, 토큰)를 채팅으로 받지 않기. 사용자는 Supabase 토큰 제공을 거절함 → 대시보드 수동 안내로 진행
- 빠진 기능(요청으로 제거): AI, 카톡 보내기/미수금 알림, .xlsx 양식, 고객명/연락처/특기사항

## 네이버 밴드 올리기 (2026-11-12 공식 문서·서버 직접 확인)
- 질문: 앱에서 사진+글 쓰고 확인 누르면 지정한 밴드에 바로 올라가게 할 수 있나 → **사진까지 자동은 불가**
- 공식 Open API 글쓰기 `POST openapi.band.us/v2.2/band/post/create` 가 받는 값: access_token, band_key, content, do_push 뿐 (사진 칸 없음). 댓글쓰기도 글(body)만. 사진 올리는 API 자체가 없음(앨범·사진은 읽기만)
- 가능한 것 ① 글만 자동: 지정 밴드에 확인 한 번으로 게시 가능. openapi.band.us 는 우리 앱 주소에서 브라우저 호출 허용(CORS 확인함) → 서버 없이 가능
- 가능한 것 ② 사진+글: 휴대폰 공유하기로 밴드 앱에 넘김(밴드 선택+게시 2번 더 누름, 밴드 미리 지정 불가) → **사용자가 이 방식 선택, v19 에서 구현**
- ①(안 만듦)을 나중에 만들 때 보안: 밴드 access_token·client_secret 은 비밀 → GitHub 금지, 채팅으로 받지 않기. 토큰은 사용자가 앱 설정 화면에 직접 붙여넣고 사장님 Supabase 에만 저장. developers.band.us 앱 등록은 사용자가 직접(로그인 필요)
- 비공식(밴드 웹 자동 조작) 방식은 약관·계정정지 위험으로 하지 않음

### 밴드에 올리기 (v19, `js/app.js`)
- 기록 화면(`editJob`): [📷 사진 추가](1600px JPEG 로 줄여 저장, **이 폰에만**) + [밴드에 올리기] 버튼. 사진만 있고 글 없는 기록도 저장 가능
- 사진 추가/빼기는 [저장] 또는 [밴드에 올리기]를 눌러야 확정. 저장 안 하고 닫으면 방금 넣은 사진은 버림
- `bandSheet(j)`: 밴드용 글 고치기(처음엔 기록 내용 그대로, 주소·금액 지우라고 안내) + 사진 눌러서 빼기 + [확인 — 밴드로 보내기] → `navigator.share({files,text})`
- 아이폰은 버튼 누른 순간에만 공유창이 열림 → 사진 파일은 화면 열 때 미리 읽어 두고, 누른 뒤에는 await 없이 바로 share 호출 (이 순서 바꾸지 말 것)
- 글은 클립보드에도 복사(밴드가 글을 빼먹으면 붙여넣기). 보낸 뒤 기록에 `bandShared`, `bandText` 저장, 버튼에 "(올림 ✔)" 표시
- 공유하기 없는 기기(PC): 글만 `band.us/plugin/share` 창으로
- 시험: Playwright 에서 share 를 가짜로 바꿔 글·사진 전달, 사진 빼기, 저장 취소 확인(오류 0). **실제 폰의 밴드 앱에서 글이 같이 들어가는지는 사용자 확인 필요**(미확인)

### 사진은 Supabase 에 안 올림 (v20, 사용자 요청: 용량 차면 안 됨)
- `js/sync.js` `pushPhotos` 에서 사진 올리는 부분을 뺌. **다시 넣지 말 것.** 양식 파일(template.*) 올리기는 그대로
- 사진은 찍은 폰의 IndexedDB 에만 있음. 기록의 `photos` id 목록은 동기화되므로 다른 폰에서는 "다른 폰에 있는 사진" 칸으로 보임
- 예전에 올라간 사진이 있으면 `fetchPhoto` 로 계속 받아옴. 사진을 지우면 클라우드 쪽도 지움(공간 회수)
- 사진을 지키는 방법은 설정 → 백업의 [사진 포함]뿐. 설정 화면에 안내 문구 넣음. 사용자에게도 알림

### 사진·밴드 표시, 크게 보기 (v20)
- 기록 카드(`jobMarks`): `📷 n`, `밴드 ✔` / `밴드 전`
- 달력 칸 왼쪽 위 네모 점(`.pdot`): 파랑 = 사진 있고 밴드 전, 초록 = 그날 사진 기록을 모두 올림
- 달력 위 [📷 밴드에 안 올린 사진 기록 n건] 누르면 목록 펼침(`state.calWait`), 누르면 그 기록 열림
- `viewPhotos(urls, start)`: 기록 화면 사진을 누르면 화면 가득. ‹ ›, 좌우 밀기, 닫기. 두 손가락 확대는 브라우저 기본 동작
