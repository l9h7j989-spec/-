# 🔧 배관 업무수첩 (배관·누수 사업 관리 웹앱)

휴대폰에서 쓰는 설치형 웹앱(PWA)입니다. 앱스토어 없이 웹 주소로 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다. 인터넷이 없어도 열립니다.

## 기능
| 화면 | 하는 일 |
|---|---|
| 오늘 | 이번 달 매출, 받을 돈 합계, 오늘 작업, 오늘 할 일, 밀린 할 일, A/S 기간 곧 끝나는 집 |
| 달력 | 날짜마다 작업 수(초록=입금완료, 빨강=미수), 할 일 점, 금액. 날짜를 누르면 그날 작업·할 일 |
| 작업 기록 | 고객·연락처·주소·내용·금액·받은 금액·사진·체크리스트(작업완료/사진/입금확인/밴드), 전화·입금요청 문자·지도·밴드 공유·견적서 만들기 |
| 견적 | 카톡 대화·메모를 붙여넣으면 **AI가 견적서 칸을 채움**(형식 없어도 됨) → 확인·수정 → **한글(HWPX) 파일 받기** / 인쇄·PDF. 안드로이드는 카톡 [공유]로 바로 받기 |
| 수금 | 미수 목록(며칠 지났는지), 입금 처리, 전화·문자, 월별 매출/수금/종류별 정리, 엑셀(CSV) 받기 |
| 설정 | 클라우드 저장(로그인), 미수금 카톡 알림, 앱 설치, 업체정보, 단가표, 견적 양식 교체, 밴드·문자 문구, 고객 목록, 백업·복원 |

**처음 설정: 사장님은 [친구용_설정안내.md](친구용_설정안내.md), 앱 관리자는 [관리자용_안내.md](관리자용_안내.md)**

## 클라우드 저장 · 카톡 알림 (v2)
- 기록·사진·견적 양식을 Supabase(무료 클라우드)에 자동 저장. 같은 이메일로 로그인하면 어느 폰에서든 같은 기록.
- 인터넷이 없을 때도 쓰고, 연결되면 자동으로 맞춤. 두 폰에서 같은 기록을 고치면 나중에 고친 것이 남음.
- 매일 오전 9시, 작업일로부터 **7일(설정 가능) 이상 입금이 안 된 작업** 목록을 내 카톡(나와의 채팅)으로 발송. 미수가 없으면 안 보냄.

## 견적서 글 입력 예시
```
고객: 김철수 010-1234-5678
주소: 서울 강남구 역삼동 123-4 101동 202호
공사: 욕실 바닥 누수 보수
누수탐지 1식 15만
PB관 교체 15A 5m 12000
타일 철거 및 복구 2㎡ 60000
부가세 별도
메모: 하자보수 1년
```

## 실제 견적서 양식으로 바꾸는 방법
1. 한글에서 사용하는 견적서 양식을 엽니다.
2. 값이 들어갈 칸에 `{{customer}}`, `{{date}}`, `{{total}}` 처럼 적습니다. 품목 표는 **한 줄에만** `{{no}} {{name}} {{spec}} {{qty}} {{unit}} {{price}} {{amount}} {{note}}`를 적습니다(품목 수만큼 줄이 늘어납니다).
3. **파일 → 다른 이름으로 저장 → 파일 형식: HWPX** 로 저장합니다.
4. 앱 설정 → 견적서 양식 → 양식 올리기.

한글 이름도 됩니다: `{{고객}} {{연락처}} {{주소}} {{공사명}} {{합계}} {{합계한글}} {{품명}} {{단가}}` 등.

> 참고: 만들어지는 파일은 `.hwpx`(한글 2014 이상에서 열리는 한글 표준 문서)입니다. 옛 `.hwp` 파일이 꼭 필요하면 한글에서 열어 `.hwp`로 다시 저장하면 됩니다.

## 네이버 밴드
- 밴드 공식 Open API의 글쓰기(`/v2.2/band/post/create`)는 **글만** 올릴 수 있고 사진은 못 올립니다.
- 그래서 앱은 휴대폰 **공유하기**로 사진+글을 밴드 앱에 넘깁니다. 밴드 앱에서 밴드 선택 → [게시]만 누르면 됩니다.
- 주소는 개인정보 보호를 위해 시·구·동까지만 넣습니다.

## 데이터 저장
- 기본 저장은 휴대폰 안(IndexedDB). 클라우드를 켜면 Supabase 에도 저장(본인 계정만 접근 가능하도록 DB 보안 정책 적용).
- 클라우드를 켜지 않으면 폰 교체·브라우저 데이터 삭제 시 사라지므로 설정 → 백업을 받아두세요.

## 배포 (휴대폰에서 열기)
정적 파일이라 아무 웹호스팅에 올리면 됩니다. 예: GitHub Pages (저장소 Settings → Pages → 브랜치 선택) 후 `https://<아이디>.github.io/<저장소>/plumbing/` 접속 → 브라우저 메뉴 → **홈 화면에 추가**.
(사진 공유·설치 기능은 `https://` 주소에서만 동작합니다.)

## 개발 메모
- `js/estimate-core.js` 글 해석·금액 계산, `js/hwpx.js` HWPX 채우기, `js/app.js` 화면, `js/db.js` 저장소, `js/sync.js` 클라우드 동기화
- `supabase/schema.sql` DB·보안정책, `supabase/schedule.sql` 매일 예약, `supabase/functions/` 카카오 연결·알림 서버 함수(Deno)
- `tools/make_template.py` 예시 양식 생성기 (`pip install python-hwpx`)
