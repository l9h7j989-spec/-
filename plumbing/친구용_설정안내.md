## 1단계. Supabase(저장 공간) 만들기 — 10분

1. https://supabase.com 접속 → **Start your project** → 가입 (사장님 이메일)
2. **New project** 누르기
   - Name: `plumbing`
   - Database Password: 아무거나 길게 → **메모장에 적기**
   - Region: **Northeast Asia (Seoul)**
   - **Create new project** → 1~2분 기다리기
3. 왼쪽 메뉴 **SQL Editor** → **New query**
4. 아래 주소를 새 창에서 열기 → 화면 글자를 **전부 선택(Ctrl+A) → 복사(Ctrl+C)**
   ```
   https://raw.githubusercontent.com/l9h7j989-spec/-/claude/happy-brahmagupta-1560fj/plumbing/supabase/schema.sql
   ```
5. Supabase 화면 빈칸에 **붙여넣기(Ctrl+V)** → 오른쪽 아래 **Run** → "Success" 나오면 성공
6. 왼쪽 메뉴 **Authentication** → **Sign In / Providers**(또는 Providers) → **Email** 누르기
   → **Confirm email** 을 **끄기** → Save
   (끄면 가입하자마자 바로 로그인됩니다)
7. **Authentication → URL Configuration** → **Site URL** 에 앱 주소 붙여넣기 → Save
8. 왼쪽 아래 톱니바퀴 **Project Settings** → **API Keys**(또는 API)
   - **Project URL** (`https://영문글자.supabase.co`) → 메모장에 적기
   - **anon** 또는 **publishable** 이라고 된 키 → 메모장에 적기
   - ⚠️ **service_role / secret** 키는 절대 다른 곳에 붙여넣지 마세요 (금고 열쇠 같은 것)

## 2단계. 휴대폰에서 클라우드 켜기 — 5분

1. 휴대폰으로 앱 주소 열기
2. 아래 **⚙️ 설정** → **☁️ 클라우드 저장**
3. Supabase 주소, 공개 키(anon/publishable)를 메모장에서 복사해 넣고 **연결**
4. 이메일·비밀번호(6자 이상) 넣고 **처음이면 가입**
5. 위쪽에 **☁️ 저장됨** 이 보이면 끝 ✅
   - 다른 폰에서도 같은 이메일로 로그인하면 같은 기록이 보입니다.

여기까지 하면 **기록 보관은 완료**입니다. 카톡 알림이 필요 없으면 6단계(앱 설치)로 가세요.

## 3단계. 카카오 개발자 앱 만들기 (카톡 알림용) — 15분

1. https://developers.kakao.com → 오른쪽 위 로그인 (**사장님 카카오 계정**)
2. **내 애플리케이션** → **애플리케이션 추가하기**
   - 앱 이름: `업무수첩`, 회사명: 상호 → 저장
3. 만든 앱 누르기 → **카카오 로그인** 메뉴 → **활성화 설정 ON**
4. **카카오 로그인 → 동의항목** → **카카오톡 메시지 전송** 찾아서 → **선택 동의** 로 설정 → 저장
5. **앱 키**(또는 **플랫폼 키 → REST API 키**) 화면
   - **REST API 키** → 메모장에 적기
   - 같은 화면(또는 **카카오 로그인 → Redirect URI**)에 **Redirect URI 등록** → 앱 주소를 **끝의 `/` 까지 똑같이** 넣기
     ```
     https://l9h7j989-spec.github.io/-/plumbing/
     ```
   - **Client Secret(클라이언트 시크릿)** 이 보이고 켜져 있으면 그 값 → 메모장에 적기
6. **플랫폼**(또는 **제품 링크 관리 → 웹 도메인**) → **Web** → 사이트 도메인에 아래 입력 → 저장
   ```
   https://l9h7j989-spec.github.io
   ```

## 4단계. 서버 기능 2개 올리기 — 10분

Supabase 사이트에서 합니다. 같은 일을 2번 반복합니다.

| 이름 (정확히 똑같이) | 하는 일 | 코드 주소 |
|---|---|---|
| `kakao-auth` | 카카오 연결 | `https://raw.githubusercontent.com/l9h7j989-spec/-/claude/happy-brahmagupta-1560fj/plumbing/supabase/functions/kakao-auth/index.ts` |

각각:
1. 왼쪽 메뉴 **Edge Functions** → **Deploy a new function** → **Via Editor**(편집기로)
2. 원래 들어있는 글자 **모두 지우기**
3. 위 표의 코드 주소를 새 창에서 열고 → 전부 복사 → 붙여넣기

5. 올린 함수의 설정(Details / Settings)에서 **Verify JWT / Enforce JWT verification** 을 **끄기** → 저장

|---|---|
| `KAKAO_REST_KEY` | 3단계 REST API 키 |
| `KAKAO_CLIENT_SECRET` | 3단계 Client Secret (없으면 이 줄은 건너뛰기) |
| `APP_URL` | `https://l9h7j989-spec.github.io/-/plumbing/` |
| `CRON_SECRET` | 아무 영문+숫자 30자 이상 직접 만들기 (예: `bae9kwan2026xxxx...`) → 메모장에 적기 |

## 매일 쓰는 법 (견적서)

1. 앱 → 📄 견적 → **새 견적서**
2. 글칸에 한 줄에 한 품목씩 적기 (**예시** 버튼을 누르면 모양이 나옵니다)
   ```
   주소: 미메이드아파트 209동 603호
   공사: 욕실 배관 공사
   배관교체 30만
   철거및복구 20만
   세척작업 20만
   부가세 별도
   ```
   - 수량·단위는 안 적어도 됩니다 (엑셀 견적서처럼 비워 두고, 금액 = 단가)
   - "PB관 15A 5m 12000" 처럼 적으면 규격·수량·단위도 들어갑니다
   - **부가세 별도**: 합계에 부가세를 더하지 않고 "*부가가치세 별도" 문구만 넣습니다 (기존 엑셀과 같음)
3. **자동 채우기** → 아래 칸 확인·수정 → **⬇ 엑셀 받기** / **⬇ 한글(HWPX) 받기** / **🖨 인쇄/PDF** 중 필요한 것
   - 받기를 누르면 "카톡으로 바로 보낼까요?" 가 나옵니다 (취소하면 휴대폰에 저장)
   - 엑셀 양식 품목 칸은 16줄입니다. 더 많으면 알려줍니다
- **⚙️ 설정 → 단가표** 에 자주 쓰는 작업을 넣어두면, 견적서에서 버튼 한 번으로 추가됩니다.
- 안드로이드에 앱을 설치했다면 카톡 글을 길게 눌러 **공유 → 업무수첩** 으로 보낼 수 있습니다 (카톡 버전에 따라 안 보일 수 있음).

## 안 될 때

| 증상 | 해결 |
|---|---|
| 위쪽에 ⚠️ 동기화 오류 | 1단계 5번(SQL Run) 했는지, 2단계에 넣은 키가 anon/publishable 인지 |
| 카카오 연결 실패 KOE006 | 3단계 Redirect URI 가 앱 주소와 글자 하나까지 같은지 (끝의 `/` 포함) |
| 카카오 연결 실패 (client_secret) | 4단계 `KAKAO_CLIENT_SECRET` 넣었는지 |
| 테스트 발송 -402 | 3단계 4번(메시지 전송 동의항목) 후 **카카오 다시 연결** |
| 매일 알림이 안 옴 | SQL Editor 에 `select * from cron.job_run_details order by start_time desc limit 5;` 붙여넣고 Run → 화면 캡처해서 앱 만든 친구에게 보내기 |

막히면 **그 화면을 캡처**해서 앱 만든 친구에게 보내세요. (키 값이 보이면 가리고 보내기)
