## 1단계. Supabase(저장 공간) 만들기 — 10분

1. https://supabase.com 접속 → **Start your project** → 가입 (사장님 이메일)
2. **New project** 누르기
   - Name: `plumbing`
   - Database Password: 아무거나 길게 → **메모장에 적기**
   - Region: **Northeast Asia (Seoul)**
   - **Create new project** → 1~2분 기다리기
3. 왼쪽 메뉴 **SQL Editor** → **New query**
4. 아래 주소를 새 창에서 열기 → 화면 글자를 **전부 선택(Ctrl+A) → 복사(Ctrl+C)**
   ```
   https://raw.githubusercontent.com/l9h7j989-spec/-/claude/happy-brahmagupta-1560fj/plumbing/supabase/schema.sql
   ```
5. Supabase 화면 빈칸에 **붙여넣기(Ctrl+V)** → 오른쪽 아래 **Run** → "Success" 나오면 성공
6. 왼쪽 메뉴 **Authentication** → **Sign In / Providers**(또는 Providers) → **Email** 누르기
   → **Confirm email** 을 **끄기** → Save
   (끄면 가입하자마자 바로 로그인됩니다)
7. **Authentication → URL Configuration** → **Site URL** 에 앱 주소 붙여넣기 → Save
8. 왼쪽 아래 톱니바퀴 **Project Settings** → **API Keys**(또는 API)
   - **Project URL** (`https://영문글자.supabase.co`) → 메모장에 적기
   - **anon** 또는 **publishable** 이라고 된 키 → 메모장에 적기
   - ⚠️ **service_role / secret** 키는 절대 다른 곳에 붙여넣지 마세요 (금고 열쇠 같은 것)

## 2단계. 휴대폰에서 클라우드 켜기 — 5분

1. 휴대폰으로 앱 주소 열기
2. 아래 **⚙️ 설정** → **☁️ 클라우드 저장**
3. Supabase 주소, 공개 키(anon/publishable)를 메모장에서 복사해 넣고 **연결**
4. 이메일·비밀번호(6자 이상) 넣고 **처음이면 가입**
5. 위쪽에 **☁️ 저장됨** 이 보이면 끝 ✅
   - 다른 폰에서도 같은 이메일로 로그인하면 같은 기록이 보입니다.

여기까지 하면 **기록 보관은 완료**입니다.

## 매일 쓰는 법 (기록)

1. 📅 달력에서 날짜 누르기 → **＋ 기록** (또는 첫 화면 **＋ 기록**)
2. 카톡·메모를 복사해서 **📋 붙여넣기** → **저장**
- 기록은 날짜와 글만 남깁니다. 달력에는 그날 기록 수가 파란 숫자로 보입니다.

**찾기**: 📅 달력 맨 위 검색칸에 글자를 넣으면(예: `209동`, `분배기`) 그 글이 들어간 기록과 할 일이 나옵니다. 누르면 그 날짜로 갑니다. 띄어 쓴 단어는 모두 들어간 것만 찾습니다.

## 누수 소견서

**처음 한 번**: ⚙️ 설정 → **누수 소견서 양식 (.hwp)** → **소견서 양식 올리기** → 쓰시던 소견서 한글 파일(.hwp) 선택. (클라우드 로그인돼 있으면 다른 폰에도 자동으로 들어감)

**매번**:
1. 📄 서류 → **💧 누수 소견서** → **＋ 새 소견서**
2. **날짜**, **누수 발생 위치**(예: 미메이드아파트 209동 603호), **수리 내역** 입력
   - 누수 발생 원인에는 수리 내역과 같은 글이 자동으로 들어갑니다
   - 나머지(A/S 신청인, 수리업체, 서명 등)는 올린 양식 그대로입니다
3. **⬇ 한글(HWP) 받기** → 파일 이름은 `누수 발생 위치 + 누수소견서` (예: `미메이드아파트 209동 603호 누수소견서.hwp`)
- 목록에서 **☑ 선택 · 삭제** 로 지울 수 있습니다

## 처음 한 번: 견적서에 들어갈 업체정보

⚙️ 설정 → **업체정보** 에 상호, 대표자, 사무실 전화(TEL), 휴대폰(H.P), 주소를 넣고 저장.
**도장 올리기**: 흰 종이에 도장을 찍고 사진을 찍어 올리면, 흰 바탕은 투명하게 바뀌어 견적서 대표 이름 옆에 찍힙니다.

## 처음 한 번: 엑셀 견적서 양식 올리기

> 양식 파일(업체정보·도장 포함)은 **인터넷에 공개되지 않습니다.** 이 폰과 사장님이 로그인한 클라우드(Supabase)에만 저장되고, 같은 계정으로 로그인한 다른 폰에는 자동으로 들어갑니다. 양식이 없으면 견적서·소견서가 만들어지지 않고 설정으로 안내합니다.

쓰시던 엑셀 견적서를 앱에 올려두면, 견적서를 만들 때 **그 엑셀 파일 그대로**(상호·도장·글꼴 포함) 칸만 채워서 줍니다.
1. 쓰시던 엑셀 견적서 파일(**.xls 그대로** 또는 .xlsx)을 휴대폰에 저장
   - .xls 를 올리면 견적서도 **.xls** 로, .xlsx 를 올리면 **.xlsx** 로 만들어집니다
2. ⚙️ 설정 → **견적서 양식 (엑셀 · 한글)** → **엑셀 양식 올리기** → 파일 선택
3. 클라우드에 로그인돼 있으면 다른 폰에도 자동으로 같은 양식이 들어갑니다

## 매일 쓰는 법 (견적서)

견적서에서 바꾸는 건 **날짜 · 현장 · 공사명 · 품목** 뿐입니다. 합계금액은 품목 금액을 더해서 자동으로 나옵니다. 나머지(상호·대표·도장·글꼴 등)는 올려둔 엑셀 양식 그대로입니다.

1. 앱 → 📄 서류 → **📄 견적서** → **＋ 새 견적서**
2. 글칸에 적고 **자동 채우기** (**예시** 버튼을 누르면 모양이 나옵니다)
   ```
   현장: 미메이드아파트 209동 603호
   공사: 욕실 배관 공사
   배관교체 30만
   철거및복구 20만
   세척작업 20만
   ```
   - 품목은 한 줄에 하나, `품명 금액` 만 적으면 됩니다 (수량·단위는 안 적어도 됨)
   - 아래 **자주 쓰는 품목** 버튼(분배기교체, 하수배관 소통작업 등)을 누르면 한 줄씩 추가됩니다. 금액은 그 줄에 적으세요
3. **⬇ 엑셀 받기** / **⬇ 한글(HWPX) 받기** / **🖨 인쇄/PDF** 중 필요한 것
   - 누르면 휴대폰에 저장됩니다
   - 엑셀 양식 품목 칸은 16줄입니다. 더 많으면 알려줍니다

**지우기**: 견적 목록에서 **☑ 선택 · 삭제** → 지울 것 누르기 → **선택 삭제**, 또는 **전체 삭제**. 지운 견적서는 되돌릴 수 없습니다.
**자주 쓰는 품목 고치기**: ⚙️ 설정 → **자주 쓰는 품목 · 단가표** 에서 이름·금액을 넣거나 지우고 저장.

## 꼭 알아둘 것

- **7일 넘게 앱을 안 쓰면** Supabase 무료 계정이 잠들 수 있습니다. 그럴 땐 supabase.com 로그인 → 프로젝트 → **Restore/Resume** 버튼. 매일 쓰면 걱정 없습니다.
- 무료 저장 용량: 기록 500MB, 사진 1GB (사진 약 2,000~3,000장).
