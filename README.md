# 지방교육행정직 문제풀이

과목(국어·영어·행정법·교육학)을 고르면 문제은행 CSV에서 25문제를 무작위로 뽑아 푸는 사이트입니다.

- 4지선다, 문제마다 제출 → 정답 여부와 해설 표시
- 한 회차 안에서는 같은 문제가 다시 나오지 않음 (다음 회차에는 겹칠 수 있음)
- 끝나면 100점 만점 점수와 틀린 문제 목록 표시
- 오답노트: 틀린 문제가 과목별로 쌓이고, 따로 풀 수 있음. 다시 맞히면 빠짐
- 다음 판에는 최근 2회차에 나온 문제를 뒤로 미뤄서 덜 겹침
- 과목별 기록: 날짜·점수, 평균·최고 점수
- 오답노트·기록은 그 기기의 브라우저에만 저장됨
- 문제은행에 25문제보다 적으면 있는 문제만 모두 출제

## 공부 시간 플래너 (`study.html`)

순공부 시간을 날짜·과목별로 적는 페이지입니다. 첫 화면 아래 **📚 공부 시간 플래너** 버튼으로 들어갑니다.

- 날짜·과목·시간(시간+분)을 골라 기록 추가, 요일 칸의 ✕로 삭제
- 주는 월~일 기준. 이번 주 합계와 목표(기본 40시간) 달성률, 남은 시간, 하루 권장량 표시
- ◀ ▶로 지난주·다음 주 보기
- 이번 주 과목별 시간, 지금까지 과목별 누적·총 시간·공부한 날·목표 달성 주 수, 주별 기록
- 과목: 국어·영어·행정법·교육학. 목표 시간 변경 가능
- 기록은 **구글 스프레드시트**에 저장됨 → 방문 기록을 지우거나 기기를 바꿔도 남음. 시트에서 표로 직접 볼 수도 있음
- 인터넷이 끊겨도 기록 가능. 다시 연결되면 자동으로 시트에 올라감 (오른쪽 위 ☁️ 표시로 상태 확인)
- 혹시 몰라 **백업 파일 받기/불러오기**도 있음 (불러오면 기존 기록에 합쳐짐)

### 구글 시트 연결하기 (처음 한 번, 5분)

나연이 구글 계정으로 하면 기록이 나연이 드라이브에 쌓입니다.

1. [sheets.new](https://sheets.new) 에서 새 스프레드시트를 만들고 이름을 `공부 기록`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 원래 있던 코드를 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여넣고 💾 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인 창이 뜨면 계정 선택 → "고급" → "(안전하지 않은 페이지)로 이동" → 허용
   (내가 만든 스크립트라 구글이 검증 안 된 앱이라고 경고하는 것. 이 스크립트는 이 시트만 읽고 씀)
6. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.
7. 둘 중 하나:
   - **추천:** `study.html` 위쪽 `const SHEET_URL = '';` 따옴표 안에 URL을 넣고 저장 → 어느 기기에서 열어도 자동 연결, 방문 기록을 지워도 다시 넣을 필요 없음
   - 또는 플래너 맨 아래 **구글 시트 주소** 칸에 붙여넣고 **연결** (이 경우 방문 기록을 지우면 주소만 다시 넣으면 됨. 기록은 시트에 그대로 있음)

연결하면 그 기기에 있던 기존 기록도 시트로 올라갑니다.

주의: 웹 앱 URL을 아는 사람은 기록을 읽고 쓸 수 있습니다. 주소를 다른 곳에 올리지 마세요.
`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 해야 반영됩니다 (URL은 그대로).

## 문제 넣는 법

`data/` 폴더의 파일을 바꾸면 됩니다.

| 과목 | 파일 |
|---|---|
| 국어 | `data/korean.csv` |
| 영어 | `data/english.csv` |
| 행정법 | `data/admin_law.csv` |
| 교육학 | `data/education.csv` |

CSV 형식 (첫 줄은 머리글):

```
문제,보기1,보기2,보기3,보기4,정답,해설
다음 중 맞춤법이 옳은 것은?,어떡해,어떻해,어떻케,어떡케,1,'어떻게 해'가 줄어든 말은 '어떡해'입니다.
```

- 정답: `1`~`4`, `①`~`④`, 또는 정답 보기의 글자 그대로
- 내용에 쉼표나 줄바꿈이 있으면 칸을 큰따옴표 `"…"`로 감싸기 (엑셀에서 저장하면 자동 처리됨)
- 엑셀 "CSV UTF-8" 또는 일반 "CSV" 저장 둘 다 읽음
- 형식이 잘못된 줄은 건너뜀

사이트 첫 화면의 **CSV 파일 직접 불러오기**로 파일을 올릴 수도 있습니다. 이 경우 그 기기의 브라우저에만 저장됩니다.

## 사이트로 열기 (GitHub Pages)

저장소 Settings → Pages → Source를 "Deploy from a branch"로, 브랜치와 `/ (root)` 폴더를 고르고 저장하면 몇 분 뒤 주소가 생깁니다.

로컬에서 볼 때는 `index.html`을 바로 열면 CSV를 못 읽으므로 `python3 -m http.server` 실행 후 `http://localhost:8000`으로 여세요.
